ComfyUI 批量工作流运行器 · 使用说明
===================================

一、启动
   双击「启动批量工作流运行器.bat」即可。
   本程序只用 Python 标准库（tkinter + urllib），不需要安装任何第三方包。

二、准备
   1. 先启动 ComfyUI，确认 http://127.0.0.1:8188 能访问。
      界面右上角会显示绿色的「ComfyUI 已启动」。
   2. 在 ComfyUI 里打开工作流，用「保存（API 格式）」导出一个 .json。
      注意要选 API 格式，不要选普通的可视化工作流文件。

三、文生图
   1. 点「选择工作流文件」选中导出的 json。
      选完后下方日志区会列出该工作流的全部节点编号，方便找 ID。
   2. 在「提示词节点 ID」填文本节点的编号。
      一般是 CLIPTextEncode / TextEncode 这类节点；
      在 ComfyUI 里选中该节点，右上角会显示它的编号。
      （本机 _api_prompt.json 里的文本节点是 496，输入项名字是 prompt。）
   3. 在「提示词列表」里粘贴提示词，一行一条，空行自动跳过。
   4. 点「执行工作流」：程序先检查 ComfyUI 是否启动，然后逐条提交、
      逐条等待，直到所有提示词全部跑完。

四、图生图
   1. 同样先选 API 格式的工作流 json。
   2. 「图片节点 ID」填图片节点的编号，一般是 LoadImage 节点
      （本机 _api_prompt.json 里是 470 / 475）。
   3. 「图片文件夹」填要批量跑图的目录，或点「浏览…」选。
      支持 png / jpg / jpeg / webp / bmp / gif / tif / avif。
   4. 点「执行工作流」：程序把每张图上传到 ComfyUI 的 input\batch，
      再把文件名写进指定节点，逐张跑完整工作流。

五、固定文本常量（两个可改的文本节点）
   两个标签页底部都有「固定文本常量」区，可以手动改写工作流里固定不变的
   文本节点内容。每次填一行，共两行可用：

       节点ID | 输入项名称（可留空） | 文本内容

   · 节点ID：文本节点的编号，在 ComfyUI 里选中该节点即可看到。
   · 输入项名称：一般留空即可，程序会自动找该节点的文本输入项
     （text / prompt / negative_prompt 等）。
     如果一个节点里有多个文本输入（例如同一个 TextEncode 节点既有
     prompt 又有 negative_prompt），在这里填具体名字才能精确改写，
     程序会在日志里提醒你。
   · 文本内容：写进去的新文本。

   这些是常量覆盖：本批每一条任务（每张图 / 每条提示词）都会写入同样的内容，
   不随图片变化。留空的行会被跳过。
   如果常量和变量节点是同一个，程序会在日志里提醒，并按「常量优先」处理。

六、看结果
   跑完弹窗提示「批量执行完成」，并给出结果文件夹路径。
   界面底部「结果文件夹」右侧点「打开文件夹」即可跳转查看。
   该目录会自动识别成 ComfyUI 的 output 目录，也可以手动改成别的路径。

   两点说明：
   · 只统计真正保存到磁盘的文件。工作流里的 PreviewImage 预览节点会产生
     一堆临时预览图（type=temp），这些不计入「生成文件数」。
   · 「结果文件夹」直接指向产物实际所在的目录。工作流的 SaveImage 常常带
     子目录（例如 output\images\qwen\gallery\results），
     程序会按真实落盘位置跳转，完成弹窗里也会列出生成的文件名。

七、其它
   · 「停止」按钮：中途叫停，当前这一条跑完就停。
   · 底部日志区实时显示每条任务的提交 / 完成 / 失败，失败会写明原因。
   · 同样的内容会追加写到同目录的「批量运行日志.log」。
   · 上次用的工作流、节点 ID、图片目录会自动记住。
   · 图生图上传的图片会堆在 ComfyUI\input\batch 里，可随时删除。
   · 单条任务失败不会中断整批；连续 3 条失败会自动中止并提示。
